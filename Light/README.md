# 光的折射與反射教學網頁

這是一個互動式網頁，用於學習光的折射與反射原理。

## 功能

- 選擇不同的光學元件：凸透鏡、凹透鏡、凸面鏡、凹面鏡
- 顯示焦點 (F) 和 2倍焦點 (2F) 的位置
- 拖拽物體來觀察像的位置變化
- 顯示光線路徑（簡化版）

## 如何使用

1. 打開 `index.html` 在瀏覽器中。
2. 從下拉選單選擇光學元件。
3. 拖拽藍色的物體來移動它。
4. 觀察綠色的像如何隨之變化，以及光線如何通過鏡頭/鏡子。

## 技術

- HTML5 Canvas 用於繪圖
- JavaScript 用於互動和計算
- 使用鏡公式計算像的位置
