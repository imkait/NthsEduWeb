# 光的路徑：透鏡與面鏡互動實驗室

高中物理光學教材。直接開啟 `index.html`，即可觀察凸透鏡、凹透鏡、凹面鏡、凸面鏡的近軸光路與成像。

## 操作

1. 選擇光學元件。
2. 拖曳畫布中的藍色物體，或使用物距滑桿與快速位置按鈕。
3. 觀察實線光路、虛線延長線、像的位置，以及即時的像距、放大率和成像性質。
4. 手機上可左右滑動光路圖；滑桿可直接用觸控或鍵盤操作。
5. 選擇凸透鏡時，頁面下方會出現物距 × 像距座標圖。可拖曳輔助線或紅色圓點、使用獨立滑桿與六個預設位置，觀察直線通過 (f, f) 時的成像變化。

## 圖像與公式

- 焦距大小固定為 100 個相對單位，物距為 45–320。
- 使用 `1/f = 1/u + 1/v`，實像距為正、虛像距為負；會聚元件的焦距為正，發散元件的焦距為負。
- 放大率為 `m = -v/u`。藍箭頭是物體，綠箭頭是像。
- 橘色是平行主軸光線，青綠色是經過透鏡中心或面鏡頂點的光線，粉紅色是經過或瞄準焦點的光線。各色實線代表實際傳播路徑，同色虛線代表作圖用的延長線。
- 當物體恰在會聚元件焦點，或焦點光線會射到圖示元件範圍外時，第三條光線不繪製並顯示原因。
- 圖示採薄透鏡與近軸球面鏡的理想化模型，不模擬透鏡厚度、球差或光強度。像超出圖面時，仍可從數值區讀取結果。
