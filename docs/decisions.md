# 決策紀錄

## 記錄格式

- 日期：
- 決策：
- 原因：
- 替代方案：
- 後續影響：

## 2026-10-20：光學教材改為互動實驗室

- 決策：保留純靜態 HTML、CSS、JavaScript，重整光學頁面為控制、光路圖、即時結果與概念筆記。
- 原因：原頁面缺少引導與成像說明，拖曳座標在縮放後可能偏移，焦點處缺乏正確呈現。
- 替代方案：導入前端框架或外部圖表套件；目前無建置需求，因此不採用。
- 後續影響：使用薄透鏡與近軸球面鏡模型；焦距固定 100 個相對單位，像超出圖面時以數值說明。

## 2026-10-21：新增獨立折射與反射模擬器

- 決策：在 `refract/` 新增純靜態 SVG 光路模擬器，電腦與平板為主要版面；入口首頁分別連結既有 `Light/` 與新 `refract/` 頁面。
- 原因：高一初學者需直接操作入射角和介質，觀察反射、折射與全反射，並直接查看司乃耳定律。
- 替代方案：沿用 `Light/` 頁面或導入前端框架；本次範圍是獨立模擬器，靜態原生技術即可完成。
- 後續影響：角度由法線量起，折射率採空氣 1.00、水 1.33、玻璃 1.50；介質固定依折射率由小到大排列，可切換光由上往下或由下往上入射；全反射時不繪製折射光線。

## 2026-10-21：折射模擬器加入光強度分配

- 決策：採未偏振光在平滑、不吸收介面的菲涅耳反射率；折射比例取 1 減反射比例。
- 原因：讓學生在觀察光路方向時，也能比較反射與折射的能量比例及全反射的 100%／0%。
- 替代方案：固定比例或僅改變光線亮度；無法正確呈現角度與介質對強度的影響。
- 後續影響：百分比數值為主要判讀依據，光線粗細僅輔助顯示；忽略介質吸收、散射與偏振差異。

## 2026-10-28：向量教材改為三階段互動實驗室

- 決策：保留純靜態 HTML、CSS、Canvas 與 Vanilla JavaScript，完成向量成分、加減法、內積三個單元，並加入數值輸入與範例按鈕。
- 原因：舊頁面標示加減法卻缺少減法；零向量難以再次拖曳，內積零向量的夾角會出現無效數值；首頁也沒有教材入口。
- 替代方案：使用外部 UI 框架或圖表套件；本教材規模不需要額外依賴。
- 後續影響：座標採整數格點並限制於 -8 到 8；畫布依目前向量自動調整比例，確保運算結果可見。內積單元固定 a = (6, 0)，零向量夾角顯示「未定義」。

## 2026-10-28：地球科學科加入外部天文教材

- 決策：首頁新增獨立地球科學科區塊，使用既有課程卡片結構連至使用者指定的 GitHub Pages 網址，並標示指定作者。
- 原因：讓地球科學教材與現有數學、物理、化學、生物、資訊科並列，方便學生從首頁進入。
- 替代方案：將教材放在物理科或直接嵌入頁面；獨立學科更符合使用者要求，外部連結也沿用現有入口模式。
- 後續影響：卡片名稱依使用者後續指定改為「克卜勒行星運動定律」；目前環境無法讀取遠端頁面內容。

## 2026-10-28：減數分裂教材改用明確的簡化模型

- 決策：主動畫維持固定染色體排列並明示未繪出互換，避免把四個圖示子細胞誤稱為必然各不相同；互換體驗改以一對同源染色體的四條染色分體及單次相互片段交換呈現。
- 原因：原動畫的結果與遺傳多樣性說明矛盾，舊互換遊戲只交換單一字母，且觸控與鍵盤難操作。
- 替代方案：把互換及隨機排列完整接入九階段 SVG 動畫；目前 SVG 各階段以固定座標手繪，全面改寫成本高，教學上先區分「固定示意」與「互換模型」更清楚。
- 後續影響：數量標示改用 2n/n 與 2C/4C/1C，並明確說明以 2n=4 的動物細胞為例；卵子形成與植物生命週期另以文字提示。
